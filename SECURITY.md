# Security Policy

## Deutsch

Sicherheitslücken bitte **nicht** öffentlich über Issues oder Pull Requests melden, sondern
über **Security and quality > Report a vulnerability** oder per E-Mail an
vulnerability[@]baumer.dev (mit Version bzw. Commit, Schritten zum Nachstellen
und Auswirkung).

Das Projekt wird ehrenamtlich gepflegt: Rückmeldung meist binnen 7 Tagen, Fixes
nur für die aktuelle Version. Bitte erst nach dem Fix veröffentlichen.

## English

Please do **not** report vulnerabilities publicly via issues or pull requests. Use
**Security and quality > Report a vulnerability** or email vulnerability[@]baumer.dev (include the version or commit, steps to reproduce, and the impact).

This project is maintained in spare time: expect a reply within about 7 days,
fixes for the current version only. Please publish details only after a fix.
